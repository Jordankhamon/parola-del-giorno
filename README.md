# Parola del giorno — sfondo per schermata di blocco

Ogni giorno legge la **parola del giorno del Vocabolario Treccani** (https://www.treccani.it/vocabolario/),
disegna uno sfondo 1170x2532 (iPhone) e aggiorna il sito: https://jordankhamon.github.io/parola-del-giorno/

L'immagine evidenzia **da dove arriva** la parola (lingua e forma d'origine) e **da quali parole è composta**.
Nessun attributo lessicografo.

File: `update.py` (estrazione), `render.py` (disegno), `site/` (pubblicato su Pages).
